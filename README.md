# Datenschutzerklärung – Busaazeig

Öffentliche Seite mit der Datenschutzerklärung der Android-App
**Busaazeig** (`ch.busazeig.app`).

Dieses Repository existiert nur, damit die Erklärung unter einer stabilen
öffentlichen URL erreichbar ist — die Play Console verlangt sie als
Pflichtangabe. Der Quellcode der App liegt in einem eigenen, privaten
Repository.

Ausgeliefert über GitHub Pages aus `index.html` im Wurzelverzeichnis:

<https://xnotgithub.github.io/busanzeige-datenschutz/>

Die Seite ist eine einzelne HTML-Datei ohne externe Ressourcen. Ändert sich,
was die App tut, gehören Text **und** das Datum im Fusszeilen-Stand angepasst.
